## ТермоСкан — финансовый план

Интерактивный финансовый план проекта «ТермоСкан» — стационарной системы ИК-мониторинга перегрева электрических соединений с AI-аналитикой.

Страница показывает разовые инвестиции и ежемесячные расходы, рассчитывает общий бюджет на период от 6 до 36 месяцев и отображает структуру затрат на диаграмме. Категории расходов можно раскрыть для просмотра отдельных статей.
